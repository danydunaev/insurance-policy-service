# Сервис учета страховых полисов

## Назначение
Приложение для автоматизации учета страховых полисов клиентов страховой компании. Позволяет вести базу клиентов, их автомобилей и оформленных полисов, а также отслеживать сроки действия страховок.

## Целевая аудитория
Менеджеры страховых компаний, страховые агенты, сотрудники отдела урегулирования убытков.

## Предметная область
Страхование автотранспорта. Учет взаимоотношений между клиентами, их транспортными средствами и оформленными полисами ОСАГО/КАСКО.

## Основные сущности
- **Пользователь (User)** — владелец автомобиля (ФИО, телефон, email).
- **Автомобиль (Car)** — транспортное средство (госномер, марка, модель, VIN).
- **Страховая компания (InsuranceCompany)** — справочник компаний.
- **Полис (Policy)** — страховой документ (тип, срок действия, цена).

## Основные функции
- Добавление нового полиса с привязкой к пользователю и автомобилю.
- Проверка срока действия полиса (истек / активен / скоро истекает).
- Расчет стоимости продления полиса с учетом коэффициентов.
- Просмотр списка всех полисов пользователя.

## План развития
На следующих этапах планируется:
- разработка веб-приложения на Django;
- подключение базы данных PostgreSQL;
- реализация системы аутентификации пользователей;
- разработка REST API с помощью Django REST Framework;
- контейнеризация приложения с помощью Docker;
- настройка CI/CD.
