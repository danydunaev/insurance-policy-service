# Сервис учёта страховых полисов

Консольное приложение на Python для автоматизации учёта страховых полисов клиентов страховой компании. Позволяет вести базу владельцев, их автомобилей и оформленных полисов ОСАГО/КАСКО, а также отслеживать сроки действия и рассчитывать стоимость продления.

## Назначение

Приложение решает задачи страхового агента:
- ведение базы клиентов (владельцев автомобилей);
- учёт автомобилей, привязанных к владельцам;
- оформление и хранение страховых полисов;
- контроль сроков действия (активен / истекает / истёк);
- поиск, фильтрация и сортировка полисов;
- расчёт стоимости продления с учётом коэффициентов;
- сохранение всех данных между запусками программы.

## Целевая аудитория

Менеджеры страховых компаний, страховые агенты, сотрудники отделов продаж и обслуживания клиентов.

## Предметная область

Страхование автотранспорта. Учёт взаимоотношений между клиентами, их транспортными средствами и оформленными полисами ОСАГО/КАСКО.

## Возможности

- **Пользователи:** добавление, поиск по ФИО, просмотр списка.
- **Автомобили:** добавление с привязкой к владельцу, поиск по госномеру, просмотр машин конкретного владельца.
- **Полисы:** добавление с привязкой к пользователю и автомобилю, проверка дубликатов.
- **Проверка статуса полиса:** активен / истекает (≤30 дней) / истёк.
- **Расчёт стоимости продления:** скидка 10% за безаварийность, надбавка 30% для водителей младше 25 лет.
- **Поиск полисов** по владельцу.
- **Фильтрация:** полисы, истекающие в ближайшие 30 дней.
- **Сортировка** полисов по цене (с использованием `lambda`).
- **Хранение данных** в JSON-файлах между запусками.

## Основные сущности

- **Пользователь (User)** — владелец автомобиля: ФИО, телефон, email.
- **Автомобиль (Car)** — транспортное средство: госномер, марка/модель, ссылка на владельца.
- **Полис (Policy)** — страховой документ: ссылка на владельца и авто, тип (ОСАГО/КАСКО), компания, срок действия (дата начала и окончания), стоимость.

## Формат хранения данных

Данные сохраняются в JSON-файлах в каталоге `data/`:

- **`users.json`** — словарь пользователей, ключ — ID:

```json
{
  "1": {
    "id": 1,
    "full_name": "Иванов Иван Иванович",
    "phone": "+7-999-123-45-67",
    "email": "ivanov@example.com"
  }
}
```

- **`cars.json`** — словарь автомобилей, ключ — ID:

```json
{
  "1": {
    "id": 1,
    "owner_id": 1,
    "license_plate": "А123БВ77",
    "model": "Toyota Camry"
  }
}
```

- **`policies.json`** — список полисов:

```json
[
  {
    "id": 1,
    "user_id": 1,
    "car_id": 1,
    "company": "Ингосстрах",
    "policy_type": "ОСАГО",
    "start_date": "2025-01-01",
    "end_date": "2026-01-01",
    "price": 7500.0
  }
]
```

Даты в JSON хранятся в формате ISO (`YYYY-MM-DD`) и автоматически преобразуются в объекты `date` при загрузке.

## Запуск программы

```bash
python main.py
```

После запуска откроется меню с 12 действиями и выходом. Данные автоматически сохраняются при выходе (`0`) и загружаются при следующем запуске.

## Запуск тестов

```bash
pytest
```

Все тесты должны завершиться статусом `passed`.

## Проверка качества кода

```bash
flake8
```

Если замечаний нет — команда не выводит ничего.

## Использованные возможности Python

- **Коллекции:** списки (`list`) для полисов, словари (`dict`) для пользователей и автомобилей.
- **Циклы:** `for` для перебора коллекций, `while` для меню.
- **Функции:** декомпозиция логики по модулям, аннотации типов, docstring.
- **Модули:** разделение кода на `users.py`, `cars.py`, `policies.py`, `storage.py`, `utils.py`.
- **Исключения:** `try/except` для безопасного ввода и работы с файлами (`ValueError`, `JSONDecodeError`, `OSError`).
- **Файлы и контекстные менеджеры:** `with open(...)` для чтения и записи JSON.
- **Lambda-функции:** ключ сортировки в `sort_policies_by_price`.
- **Работа с датами:** модуль `datetime`, классы `date`, `timedelta`.
